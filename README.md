# Philos Bot

Telegram-бот для календаря академических философских мероприятий.

Бот предназначен для сбора, хранения и отображения информации о философских конференциях, докладах, семинарах, школах и академических дедлайнах.

## Текущий статус

Сейчас реализована базовая версия бота:

- запуск через `main.py`;
- чтение токена из `.env`;
- команды `/start`, `/help`, `/today`, `/week`, `/submit`;
- обработчики команд вынесены в `handlers.py`.

## Установка и запуск

1. Создать виртуальное окружение:

```powershell
py -m venv .venv
```

2. Активировать виртуальное окружение:

```powershell
.\.venv\Scripts\Activate.ps1
```

3. Установить зависимости:

```powershell
python -m pip install -r requirements.txt
```

4. Создать файл `.env` на основе `.env.example`.

В файле `.env` должна быть строка:

```env
BOT_TOKEN=your_real_bot_token_here
```

5. Запустить бота:

```powershell
python main.py
```

## Структура проекта

```text
Philos_Bot/

  .gitignore
  README.md
  requirements.txt

```

## Важно

Файл `.env` не должен попадать в GitHub, потому что в нем хранится токен бота.

Папка `.venv` также не должна попадать в GitHub, потому что виртуальное окружение создается локально на компьютере разработчика.
